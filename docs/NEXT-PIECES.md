调性一路是 g → g → d → b → a → c → C。莫四十到维瓦尔第是**同调**（g 小调），衔接最顺；七交 a 小调是 C 大调的关系小调，给终曲铺路。

贯穿规则不变：
- **红色只给命运动机**。每首曲子跑一遍 `find_motifs`（三短一长、同音反复），找到“伪装”的命运动机才点红，其他发声音符用各段自己的高光色。
- **金色只给终曲**。
- 每段一个具体物件当双关，不照字面图解；AI 的梗用面无表情的仪器读数来讲。

## 3. 维瓦尔第《夏》第三乐章 Presto：暴风雨

**音乐**：g 小调 3/4，弦乐全体十六分音符同音反复（震音），独奏小提琴一路往下冲的音阶，像闪电和冰雹。乐谱里自带维瓦尔第自己写的十四行诗，这一段的诗句是：

> *Ah che pur troppo i suoi timor son veri / Tuona e fulmina il ciel e grandinoso / Tronca il capo alle spiche e a' grani alteri.*
> （唉，他的恐惧果然成真：天雷闪电，冰雹砸下，把高傲的麦穗齐齐削断。）

**画面语言：气象站**。暴风雨的读数。
- **示波器 / 地震仪**：弦乐的同音反复画成示波器上的高频波形，力度就是振幅。
- **频谱柱 = 麦田**：底部一排频谱柱画成麦穗，独奏的下行音阶扫过时一排排被“削断”（诗里的那一句）。
- **冰雹 = 音符**：每个十六分音符是一颗冰雹砸下来，在地面溅起小环。
- **气象雷达**：一个扫描圆，独奏音阶就是雷达扫过的回波。
- **集合预报的“意大利面图”**（AI 梗）：天气预报会同时算几十条可能的路径，正好对应模型对“下一段旋律”的多次采样，画成一束发散的线，真实的旋律是其中一条。读数写 `ensemble n=32  T=0.9`。
- **特写**：独奏小提琴，琴弓十六分音符换弓（复用 `Fiddle`，这里运动模糊最出效果）；气压计指针猛降。
- **字**：诗句用衬线斜体，一行一行被闪电照亮。

**配色 `storm`**：黑、石板灰绿、鼠尾草灰、灰白。闪电那一两帧整屏反相（和贝五→莫四十用的 glaze 反相是同一个机制）。

**衔接（莫四十 → 夏）**：同为 g 小调。青花瓷盘被第一阵冰雹砸中，釉面裂纹（2D 线）蔓延，porcelain 慢慢转成 storm。

**技术**：MIDI 是 Mutopia 的 CC BY-SA，`summer-score-2.mid` 就是这个乐章，五个声部齐全，直接走 `read_midi_notes`。片尾标注 CC BY-SA 署名。

## 4. 巴赫 托卡塔与赋格 BWV 565：管风琴

**音乐**：d 小调。开头 A–G–A 波音加延长记号，停顿；下行音阶；然后在低音 D 的持续音上，从下往上堆出那个著名的减七和弦。之后进入 Prestissimo。乐谱里延长记号多，和我们已有的“延长记号燃烧 + 休止全黑”的系统正好对上。

**画面语言：管风琴 = 机房**。
- **音管 = 机架**：一排排音管，发声的那根亮起来、管口喷出气流粒子。远看是教堂管风琴，近看管壁上有指示灯和标签，像服务器机架。
- **音栓 = 超参数**（AI 梗）：琴台上的音栓拉杆，标签一半是真名一半是参数：`Principal 8'`、`Trompette 8'`、`temperature 0.8`。拉出一根，音色就变。
- **风箱 = 包络**：风箱随音量起伏，就是 `audio.json` 里的 rms。
- **混响看得见**：每次延长记号停住，余音在教堂里画成一圈圈衰减的环，读数 `RT60 4.2 s`。
- **玫瑰彩窗**：每个和弦点亮彩窗的一片。后期的 grade 会放过高饱和色，所以彩窗是全片唯一的多彩时刻，用一次，很显眼。
- **训练数据**（AI 梗）：巴赫的 371 首众赞歌是音乐 AI 最经典的训练集（DeepBach、2019 年 Google 的巴赫 Doodle）。一行等宽小字：`training set: J. S. Bach, 371 chorales`。
- **特写**：手指按下琴键时，联动的拉杆（tracker action）一路传到音管，和自动钢琴纸卷那段呼应；脚踩踏板的低音 D。

**配色 `stone`**：黑、深棕灰、石灰岩、象牙白，金属管偏锡灰。

**衔接（夏 → 巴赫）**：最后一道闪电的竖线定格，变成一排音管。storm → stone。

**技术**：Mutopia 公有领域。MIDI 是死板的每分钟 60 拍，延长记号只在 LilyPond 源码里，所以速度图要手写（fermatas 表我们已有）。音色用 GM 19（教堂管风琴），混响加长。

## 5. 格里格《山魔王》：越跑越快

**音乐**：b 小调。同一个短乐句反复几十遍，越来越高、越来越响、越来越快（谱上从 ♩=138 到 Più vivo 154，然后 *sempre stretto sin al fine*，一直加速到结尾），最后崩塌。我们手上的是钢琴独奏谱，加速正好写进速度图。

**画面语言：山腹里的机房**。
- **循环计数器**（AI 梗）：每一遍乐句是一轮迭代，`iter 1, 2, 3…`，时钟频率、风扇转速、温度一起往上爬。结尾读数是 `loss: NaN`。
- **节拍器回场**：贝五里那个线稿节拍器又出现，越摆越快，最后摆锤飞出去。
- **矿车 = 纸卷**：矿车顺着铁轨冲，铁轨就是滚动的乐谱，速度跟着速度图走。
- **山魔 = 剪纸皮影**：2D 剪纸山魔剪影，被火光投在洞壁上，随重音跺脚。这是最“3 渲 2”的一段。
- **剪辑密度跟着速度**：开头一个乐句一刀，结尾一拍一刀。

**配色 `cave`**：黑、焦褐、火光赭红、热白。用 `rampMix` 让整段越快越往红白偏，像 CPU 过热。

**衔接（巴赫 → 格里格）**：管风琴最后的低音 D，镜头穿过教堂地板往下沉，音管变成钟乳石和机架。

**技术**：Mutopia 公有领域，MIDI 左右手两轨。中间要剪一刀（pp 开头 → stretto），用已有的 `gap_before` / 分段机制。

## 6. 贝多芬第七 II 小快板：一层一层

**音乐**：a 小调。木管一个 a 小调和弦开门，然后低音弦乐 pp 奏出“长–短短–长–长”的节奏。主题每重复一次就加一层：中提琴和大提琴，再加第二小提琴的对旋律，再加第一小提琴，最后全团 ff。在格里格的狂乱之后，这里是一口气、一段静。

**画面语言：叠起来的网络层**。
- **每加一个声部 = 加一层**：半透明的玻璃板在纵深上一块块排开，每块上刻着那个声部的旋律线，节奏像激活值一样一层层传过去。这是“深度网络”最直白的视觉双关，但音乐结构本身就是这样，不是硬贴的。
- **对旋律 = 穿过各层的一条曲线**。
- **铜版蚀刻**：排线加重、色阶分得细，像丢勒的版画；这一段几乎没有颜色。
- **特写**：大提琴的长弓（复用），蚀刻刀刻线的笔尖。

**配色 `ash`**：纯中性黑白灰，像银盐照片。全片最克制的一段。

**衔接（格里格 → 七交）**：山崩之后全黑，灰尘落定；木管的 a 小调和弦从尘埃里升起来。

**技术**：Mutopia 公有领域，12 轨，和贝五第一乐章同一套编排，直接复用管线。原曲一个变奏就有三十多秒，要按乐句剪成三层（第一层 → 跳到第一小提琴进来 → 跳到全团），用分段机制拼。

## 7. 贝多芬第五 III→IV：光

**音乐**：第三乐章结尾，定音鼓在 C 上 pp 持续敲，弦乐在黑暗里慢慢爬升、渐强，然后不间断地冲进第四乐章的 C 大调，长号第一次进来。这是整部交响曲从 c 小调到 C 大调的那一刻，也是整支片子的落点。

**画面语言：从黑到金，所有物件回场**。
- **桥段**：全黑，只有一面定音鼓的鼓皮特写，鼓皮微微颤动，鼓面上是红色（命运的红）。随着渐强，光一点点进来。
- **C 大调第一拍**：整屏翻成金色，金色在全片第一次出现。
- **长号**：整部交响曲憋了三个乐章，这里第一次进来。读数 `trombones: tacet 3 movements → ff`。
- **所有物件回场**：琴槌、88 键、青花瓷琴、小提琴、音管、节拍器、玻璃层，像谢幕一样排开，统统换成金色。
- **结尾那一串 C 大调和弦**（贝五那个“怎么也结束不了”的结尾）：每一下切回前面一段的一个镜头，最后一下全黑。读数 `converged.`
- **命运动机**：红的三短一长最后一次出现，变成金色。

**配色 `gold`**：黑、深琥珀、金、暖白。

**衔接（七交 → 五交终曲）**：七交收在弱处，直接落进桥段的黑暗里。

**技术**：CC0 的“超还原”钢琴缩谱（MusicXML，三行谱，整部交响曲）。需要：
1. 把桥段和终曲从 1616 小节里切出来；
2. 三行谱按音区拆回乐器（低音 → 定音鼓 / 低音提琴，中音 → 长号 / 圆号……），合成时才有乐队的声音。

终曲开头和结尾那串和弦不相连，要剪一刀。

## 为“通用版”留的伏笔

将来要做成“给任何乐谱都能出片”，最可复用的不是某一段场景，而是**“乐谱特征 → 画面语言”的对应关系**。这几首正好覆盖了常见的几类特征：

| 乐谱特征（可以自动检测） | 画面语言 | 本片里的例子 |
|---|---|---|
| 动机反复 / 模仿 | 追踪注意力、座位图、红圈批注 | 贝五 |
| 延长记号、全团休止 | 燃烧、全黑、混响环 | 贝五、巴赫 |
| 同音反复 / 震音 | 示波器、冰雹 | 维瓦尔第 |
| 固定音型 + 渐快 | 循环计数器、节拍器、超频 | 格里格 |
| 声部逐层进入 | 叠起来的网络层 | 七交 |
| 全奏强拍 | 镜头冲击、全屏大字 | 各段 |
| 调式从小调转到大调 | 换配色（黑 → 金） | 五交终曲 |
| 键盘 / 弦乐 / 管乐 / 管风琴 | 可演奏的乐器模型 | 各段 |

每做完一首，就把它的场景整理成“特征 → 场景模板”，以后 agent 拿到一份新乐谱，先跑分析找特征，再从模板库里挑场景、配色、衔接。
